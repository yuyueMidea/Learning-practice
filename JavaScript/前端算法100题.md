## 1. 两数之和

**LeetCode 1**

### 题目

给定整数数组 `nums` 和目标值 `target`，找到两个数，使它们的和等于 `target`，返回下标。

```js
[2, 7, 11, 15]
target = 9
```

返回：

```js
[0, 1]
```

### 解题思路

对于当前数字：

```text
x
```

我们需要寻找：

```text
target - x
```

使用 `Map` 保存已经遍历过的数字。

### JS 标准答案

```js
function twoSum(nums, target) {
    const map = new Map()

    for (let i = 0; i < nums.length; i++) {
        const need = target - nums[i]

        if (map.has(need)) {
            return [map.get(need), i]
        }

        map.set(nums[i], i)
    }

    return []
}
```

### 复杂度

```text
时间：O(n)
空间：O(n)
```

### 面试追问

如果要求两个数而不是返回下标，可以怎样优化？

可以只保存 `Set`：

```js
const set = new Set()
```

### 易错点

不能把当前元素先放入 Map 再寻找，否则可能把自己和自己配对。

## 3. 除自身以外数组的乘积

**LeetCode 238**

### 题目

```js
[1, 2, 3, 4]
```

返回：

```js
[24, 12, 8, 6]
```

### 思路

当前位置：

```text
左侧所有乘积 × 右侧所有乘积
```

先计算前缀，再倒序乘以后缀。

### JS 标准答案

```js
function productExceptSelf(nums) {
    const result = new Array(nums.length)

    let prefix = 1

    for (let i = 0; i < nums.length; i++) {
        result[i] = prefix
        prefix *= nums[i]
    }

    let suffix = 1

    for (let i = nums.length - 1; i >= 0; i--) {
        result[i] *= suffix
        suffix *= nums[i]
    }

    return result
}
```

### 复杂度

```text
时间：O(n)
额外空间：O(1)
```

### 面试追问

为什么不直接计算全部乘积然后除以 `nums[i]`？

因为存在 `0`，而且题目通常要求 O(1) 额外空间。

### 易错点

前缀和后缀不要额外创建两个数组，可以直接复用 `result`。

## 4. 最大子数组和

**LeetCode 53**

### 题目

```js
[-2,1,-3,4,-1,2,1,-5,4]
```

最大连续子数组：

```text
[4,-1,2,1]
```

结果：

```text
6
```

### 思路

定义：

```text
current = 以当前位置结尾的最大连续和
```

状态：

```text
current = max(nums[i], current + nums[i])
```

### JS 标准答案

```js
function maxSubArray(nums) {
    let current = nums[0]
    let answer = nums[0]

    for (let i = 1; i < nums.length; i++) {
        current = Math.max(
            nums[i],
            current + nums[i]
        )

        answer = Math.max(
            answer,
            current
        )
    }

    return answer
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

这个算法叫什么？

Kadane Algorithm。

### 易错点

不要初始化：

```js
answer = 0
```

因为数组可能全部是负数。

## 5. 移动零

**LeetCode 283**

### 题目

将所有 `0` 移到数组末尾，同时保持非零元素相对顺序。

```js
[0,1,0,3,12]
```

变成：

```js
[1,3,12,0,0]
```

### 思路

使用一个指针 `write` 表示下一个非零元素应该放在哪里。

### JS 标准答案

```js
function moveZeroes(nums) {
    let write = 0

    for (let i = 0; i < nums.length; i++) {
        if (nums[i] !== 0) {
            ;[nums[write], nums[i]] =
                [nums[i], nums[write]]

            write++
        }
    }
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

能不能减少交换次数？

可以先覆盖所有非零元素，最后统一填 0。

### 易错点

题目要求通常是“原地修改”，不能简单返回新数组。

## 6. 多数元素

**LeetCode 169**

### 题目

数组中出现次数超过 `n / 2` 的元素。

```js
[2,2,1,1,1,2,2]
```

返回：

```text
2
```

### 思路

Boyer-Moore 投票算法。

核心：

```text
count = 0

遇到候选值：
count++

否则：
count--

count 为 0 时重新选择候选
```

### JS 标准答案

```js
function majorityElement(nums) {
    let candidate = null
    let count = 0

    for (const num of nums) {
        if (count === 0) {
            candidate = num
        }

        count +=
            num === candidate
                ? 1
                : -1
    }

    return candidate
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

如果不是严格超过 `n/2`，这个算法还能直接使用吗？

不能，需要修改问题模型或使用其他方法。

### 易错点

Boyer-Moore 的成立依赖“多数元素一定存在”这一条件。

## 7. 丢失的数字

**LeetCode 268**

### 题目

数组包含 `[0,n]` 中 `n` 个不同数字，找缺失的一个。

```js
[3,0,1]
```

结果：

```text
2
```

### 思路

异或具有：

```text
x ^ x = 0
x ^ 0 = x
```

### JS 标准答案

```js
function missingNumber(nums) {
    let result = nums.length

    for (let i = 0; i < nums.length; i++) {
        result ^= i
        result ^= nums[i]
    }

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

还可以用什么方法？

求和公式：

```text
n * (n + 1) / 2
```

然后减去数组元素之和。

### 易错点

位运算在 JS 中使用的是 32 位有符号整数语义，超大整数场景不能照搬。

## 8. 轮转数组

**LeetCode 189**

### 题目

```js
[1,2,3,4,5,6,7]
k = 3
```

变成：

```js
[5,6,7,1,2,3,4]
```

### 思路

三次反转：

```text
整体反转
前 k 个反转
后 n-k 个反转
```

### JS 标准答案

```js
function rotate(nums, k) {
    k %= nums.length

    function reverse(left, right) {
        while (left < right) {
            ;[nums[left], nums[right]] =
                [nums[right], nums[left]]

            left++
            right--
        }
    }

    reverse(0, nums.length - 1)
    reverse(0, k - 1)
    reverse(k, nums.length - 1)
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 易错点

一定先：

```js
k %= nums.length
```

否则 `k` 很大时没有必要。

## 9. 合并两个有序数组

**LeetCode 88**

### 题目

```text
nums1 = [1,2,3,0,0,0]
nums2 = [2,5,6]
```

结果：

```text
[1,2,2,3,5,6]
```

### 思路

从尾部开始比较。

为什么从后往前？

因为 `nums1` 后面的空间就是给合并结果准备的。

### JS 标准答案

```js
function merge(nums1, m, nums2, n) {
    let i = m - 1
    let j = n - 1
    let k = m + n - 1

    while (j >= 0) {
        if (
            i >= 0 &&
            nums1[i] > nums2[j]
        ) {
            nums1[k--] = nums1[i--]
        } else {
            nums1[k--] = nums2[j--]
        }
    }
}
```

### 复杂度

```text
时间：O(m+n)
空间：O(1)
```

### 易错点

不要从前往后覆盖 `nums1`，否则会覆盖还没有读取的数据。

## 10. 前 K 个高频元素

**LeetCode 347**

### 题目

找到数组中出现频率最高的 `k` 个元素。

### 思路

计数后使用“桶”。

```text
桶下标 = 出现次数
```

### JS 标准答案

```js
function topKFrequent(nums, k) {
    const count = new Map()

    for (const num of nums) {
        count.set(
            num,
            (count.get(num) || 0) + 1
        )
    }

    const buckets =
        Array.from(
            { length: nums.length + 1 },
            () => []
        )

    for (const [num, freq] of count) {
        buckets[freq].push(num)
    }

    const result = []

    for (
        let freq = buckets.length - 1;
        freq >= 0 && result.length < k;
        freq--
    ) {
        for (const num of buckets[freq]) {
            result.push(num)

            if (result.length === k) {
                break
            }
        }
    }

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(n)
```

### 面试追问

还能怎么做？

最经典的是：

```text
小顶堆
```

复杂度可以做到：

```text
O(n log k)
```

### 易错点

桶排序不是传统意义上的“对原数组排序”，它利用的是“频率范围有限”。

## 11. 有效的字母异位词

**LeetCode 242**

### 题目

```text
anagram
nagaram
```

判断两个字符串是否由相同字符组成。

### 思路

统计字符频率。

### JS 标准答案

```js
function isAnagram(s, t) {
    if (s.length !== t.length) {
        return false
    }

    const count = new Map()

    for (const char of s) {
        count.set(
            char,
            (count.get(char) || 0) + 1
        )
    }

    for (const char of t) {
        if (!count.has(char)) {
            return false
        }

        count.set(
            char,
            count.get(char) - 1
        )

        if (count.get(char) < 0) {
            return false
        }
    }

    return true
}
```

### 复杂度

```text
时间：O(n)
空间：O(k)
```

### 易错点

`Map` 的键不一定只能是 ASCII 字符；Unicode 场景要考虑 JS 字符串的 UTF-16 行为。

## 13. 字母异位词分组

**LeetCode 49**

### 题目

```js
["eat","tea","tan","ate","nat","bat"]
```

得到：

```js
[
    ["eat","tea","ate"],
    ["tan","nat"],
    ["bat"]
]
```

### 思路

异位词排序以后得到相同 Key。

### JS 标准答案

```js
function groupAnagrams(strs) {
    const map = new Map()

    for (const str of strs) {
        const key = [...str]
            .sort()
            .join('')

        if (!map.has(key)) {
            map.set(key, [])
        }

        map.get(key).push(str)
    }

    return [...map.values()]
}
```

### 复杂度

```text
时间：O(n * k log k)
空间：O(nk)
```

### 面试追问

如何降低排序成本？

如果字符集固定，可以用字符频率构造 Key。

### 易错点

直接使用：

```js
JSON.stringify([...str])
```

虽然能工作，但通常没有必要。

## 14. 最长公共前缀

**LeetCode 14**

### 思路

让第一个字符串作为候选前缀，逐个缩短。

### JS 标准答案

```js
function longestCommonPrefix(strs) {
    if (!strs.length) {
        return ''
    }

    let prefix = strs[0]

    for (let i = 1; i < strs.length; i++) {
        while (
            !strs[i].startsWith(prefix)
        ) {
            prefix = prefix.slice(0, -1)

            if (!prefix) {
                return ''
            }
        }
    }

    return prefix
}
```

### 复杂度

```text
时间：O(S)
```

其中 `S` 是所有字符串字符总量的量级。

### 易错点

空数组要单独处理。

## 15. 验证回文串

**LeetCode 125**

### 思路

双指针：

```text
left → 
← right
```

跳过非字母数字字符。

### JS 标准答案

```js
function isPalindrome(s) {
    s = s.toLowerCase()

    let left = 0
    let right = s.length - 1

    while (left < right) {
        while (
            left < right &&
            !/[a-z0-9]/.test(s[left])
        ) {
            left++
        }

        while (
            left < right &&
            !/[a-z0-9]/.test(s[right])
        ) {
            right--
        }

        if (s[left] !== s[right]) {
            return false
        }

        left++
        right--
    }

    return true
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 易错点

不要默认中文、emoji 等复杂 Unicode 字符也能使用 ASCII 正则正确处理。

## 17. 最长回文子串

**LeetCode 5**

### 思路

以每个位置为中心向两边扩展。

需要分别处理：

```text
奇数长度回文
偶数长度回文
```

### JS 标准答案

```js
function longestPalindrome(s) {
    if (s.length < 2) {
        return s
    }

    let start = 0
    let end = 0

    function expand(left, right) {
        while (
            left >= 0 &&
            right < s.length &&
            s[left] === s[right]
        ) {
            left--
            right++
        }

        return right - left - 1
    }

    for (let i = 0; i < s.length; i++) {
        const len1 = expand(i, i)
        const len2 = expand(i, i + 1)

        const len = Math.max(len1, len2)

        if (len > end - start + 1) {
            start =
                i - Math.floor((len - 1) / 2)

            end =
                i + Math.floor(len / 2)
        }
    }

    return s.slice(start, end + 1)
}
```

### 复杂度

```text
时间：O(n²)
空间：O(1)
```

### 面试追问

还有 O(n) 方法吗？

有，Manacher 算法。

### 易错点

奇数和偶数回文中心不同。

## 18. 字符串压缩

**LeetCode 443**

### 题目

```js
["a","a","b","b","c","c","c"]
```

压缩为：

```text
a2b2c3
```

### 思路

使用读写双指针。

### JS 标准答案

```js
function compress(chars) {
    let read = 0
    let write = 0

    while (read < chars.length) {
        const current = chars[read]
        let count = 0

        while (
            read < chars.length &&
            chars[read] === current
        ) {
            read++
            count++
        }

        chars[write++] = current

        if (count > 1) {
            for (const digit of String(count)) {
                chars[write++] = digit
            }
        }
    }

    return write
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 易错点

数字大于 9 时需要拆成多个字符。

## 19. 三数之和

**LeetCode 15**

### 思路

排序后：

```text
固定 i
left = i + 1
right = n - 1
```

根据三数之和移动指针。

### JS 标准答案

```js
function threeSum(nums) {
    nums.sort((a, b) => a - b)

    const result = []

    for (let i = 0; i < nums.length - 2; i++) {
        if (
            i > 0 &&
            nums[i] === nums[i - 1]
        ) {
            continue
        }

        let left = i + 1
        let right = nums.length - 1

        while (left < right) {
            const sum =
                nums[i] +
                nums[left] +
                nums[right]

            if (sum === 0) {
                result.push([
                    nums[i],
                    nums[left],
                    nums[right]
                ])

                while (
                    left < right &&
                    nums[left] === nums[left + 1]
                ) {
                    left++
                }

                while (
                    left < right &&
                    nums[right] === nums[right - 1]
                ) {
                    right--
                }

                left++
                right--
            } else if (sum < 0) {
                left++
            } else {
                right--
            }
        }
    }

    return result
}
```

### 复杂度

```text
时间：O(n²)
空间：O(log n) ~ O(n)，取决于排序实现
```

### 易错点

“去重”是这道题的关键之一。

## 20. 盛最多水的容器

**LeetCode 11**

### 思路

面积：

```text
min(height[left], height[right])
×
(right - left)
```

每次移动较矮的一边，因为移动更高的一边只会缩短宽度而不能提高短板。

### JS 标准答案

```js
function maxArea(height) {
    let left = 0
    let right = height.length - 1
    let answer = 0

    while (left < right) {
        const area =
            Math.min(
                height[left],
                height[right]
            ) * (right - left)

        answer = Math.max(answer, area)

        if (height[left] < height[right]) {
            left++
        } else {
            right--
        }
    }

    return answer
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 易错点

## 23. 有序数组的平方

```js
function sortedSquares(nums) {

            right--
        }
```

## 28. 最小覆盖子串

**LeetCode 76**

### 题目

```text
s = "ADOBECODEBANC"
t = "ABC"
```

答案：

```text
"BANC"
```

### 思路

右指针扩张，满足条件后左指针尽量收缩。

### JS 标准答案

```js
function minWindow(s, t) {
    if (s.length < t.length) {
        return ''
    }

    const need = new Map()

    for (const c of t) {
        need.set(
            c,
            (need.get(c) || 0) + 1
        )
    }

    const window = new Map()

    let left = 0
    let valid = 0

    let start = 0
    let minLen = Infinity

    for (
        let right = 0;
        right < s.length;
        right++
    ) {
        const c = s[right]

        if (need.has(c)) {
            window.set(
                c,
                (window.get(c) || 0) + 1
            )

            if (
                window.get(c) === need.get(c)
            ) {
                valid++
            }
        }

        while (valid === need.size) {
            if (
                right - left + 1 <
                minLen
            ) {
                start = left
                minLen =
                    right - left + 1
            }

            const d = s[left]

            if (need.has(d)) {
                if (
                    window.get(d) === need.get(d)
                ) {
                    valid--
                }

                window.set(
                    d,
                    window.get(d) - 1
                )
            }

            left++
        }
    }

    return minLen === Infinity
        ? ''
        : s.slice(
            start,
            start + minLen
        )
}
```

### 复杂度

```text
时间：O(n)
空间：O(k)
```

### 面试追问

为什么 `valid === need.size` 就说明窗口满足要求？

因为 `valid` 统计的是已经达到目标频率的字符种类数。

### 易错点

只比较：

```js
window.size === need.size
```

是不够的，还需要考虑字符出现次数。

```js
class MinStack {
    constructor() {
        this.stack = []
        this.minStack = []
    }

    push(val) {
        this.stack.push(val)

        if (
            this.minStack.length === 0 ||
            val <=
                this.minStack[
                    this.minStack.length - 1
                ]

        }
```

## 66. 子集

**LeetCode 78**

### 思路

每个元素都有两个选择：

```text
选
不选
```

也可以写成：

```text
选择当前元素
递归
撤销选择
```

### JS 标准答案

```js
function subsets(nums) {
    const result = []
    const path = []

    function backtrack(start) {
        result.push([...path])

        for (
            let i = start;
            i < nums.length;
            i++
        ) {
            path.push(nums[i])

            backtrack(i + 1)

            path.pop()
        }
    }

    backtrack(0)

    return result
}
```

### 复杂度


### 易错点

```js
result.push([...path])
```

不能：

```js
result.push(path)
```

否则所有结果都指向同一个数组。

## 67. 全排列

**LeetCode 46**

### 思路

当前位置可以选择任意还没有使用的数字。

### JS 标准答案

```js
function permute(nums) {
    const result = []
    const path = []
    const used =
        new Array(nums.length).fill(false)

    function backtrack() {
        if (
            path.length === nums.length
        ) {
            result.push([...path])
            return
        }

        for (
            let i = 0;
            i < nums.length;
            i++
        ) {
            if (used[i]) {
                continue
            }

            used[i] = true
            path.push(nums[i])

            backtrack()

            path.pop()
            used[i] = false
        }
    }

    backtrack()

    return result
}
```

```text

排列：used
```

**LeetCode 39**

### 思路

数字可以重复使用，所以递归下一层时：

```text
仍然传 i
```

### JS 标准答案

```js
function combinationSum(
    candidates,
    target
) {
    const result = []
    const path = []

    function backtrack(
        start,
        remain
    ) {
        if (remain === 0) {
            result.push([...path])
            return
        }

        for (
            let i = start;
            i < candidates.length;
            i++
        ) {
            const num = candidates[i]

            if (num > remain) {
                continue

            backtrack(
                i,
                remain - num
            )

            path.pop()
        }
    }

}
```

### 易错点

可以重复使用当前数字，所以是：

```js
backtrack(i, ...)
```

而不是：

```js
backtrack(i + 1, ...)
```

```js
    candidates,
    target
```

## 71. 括号生成

**LeetCode 22**

### 思路

维护两个数量：

```text

```

规则：

```text
open < n 才能继续加 (
close < open 才能加 )
```

### JS 标准答案

```js
function generateParenthesis(n) {
    const result = []
    const path = []

    function backtrack(
        open,
        close
    ) {
        if (
            path.length === 2 * n
        ) {
            result.push(path.join(''))
            return
        }

        if (open < n) {
            path.push('(')

                open + 1,

            )
```

## 72. 单词搜索

**LeetCode 79**

### 思路

从每个位置开始 DFS：

```text
上
下
左
右
```

访问过的位置不能再次使用。

### JS 标准答案

```js
function exist(board, word) {
    const rows = board.length
    const cols = board[0].length

    function dfs(r, c, index) {
        if (index === word.length) {
            return true
        }

        if (
            r < 0 ||
            r >= rows ||
            c < 0 ||
            c >= cols ||
            board[r][c] !== word[index]
        ) {
            return false
        }

        const temp = board[r][c]
        board[r][c] = '#'

        const found =
            dfs(r + 1, c, index + 1) ||
            dfs(r - 1, c, index + 1) ||
            dfs(r, c + 1, index + 1) ||
            dfs(r, c - 1, index + 1)

        board[r][c] = temp

        return found
    }

    for (let r = 0; r < rows; r++) {
        for (let c = 0; c < cols; c++) {
            if (dfs(r, c, 0)) {
                return true
            }
        }
    }

    return false
}
```

### 复杂度

最坏情况呈指数级。

### 易错点

“访问标记”必须在回溯时恢复。

## 73. 分割回文串

**LeetCode 131**

### 思路

枚举每一个切分位置：

```text
当前子串是回文？
    ↓
是 → 选择
    ↓
继续递归
```

### JS 标准答案

```js
function partition(s) {
    const result = []
    const path = []

    function isPalindrome(left, right) {
        while (left < right) {
            if (s[left] !== s[right]) {
                return false
            }

            left++
            right--
        }

        return true
    }

    function backtrack(start) {
        if (start === s.length) {
            result.push([...path])
            return
        }

        for (
            let end = start;
            end < s.length;
            end++
        ) {
            if (
                !isPalindrome(
                    start,
                    end
                )
            ) {
                continue
            }

            path.push(
                s.slice(start, end + 1)
            )

            backtrack(end + 1)

            path.pop()
        }
    }

    backtrack(0)

    return result
}
```

### 复杂度

指数级。

### 易错点

回溯题一定要明确：

```text
状态
选择
终止条件
撤销选择
```

```js
        nums.reduce(
            (a, b) => a + b,
```

## 83. 最长公共子序列

**LeetCode 1143**

### 思路

如果：

```text
text1[i] === text2[j]
```

则：

```text
dp[i][j] = dp[i-1][j-1] + 1
```

否则：

```text
max(
    dp[i-1][j],
    dp[i][j-1]
)
```

### JS 标准答案

```js
function longestCommonSubsequence(
    text1,
    text2
) {
    const m = text1.length
    const n = text2.length

    const dp =
        Array.from(
            { length: m + 1 },
            () => new Array(n + 1).fill(0)
        )

    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            if (
                text1[i - 1] ===
                text2[j - 1]
            ) {
                dp[i][j] =
                    dp[i - 1][j - 1] + 1
            } else {
                dp[i][j] =
                    Math.max(
                        dp[i - 1][j],
                        dp[i][j - 1]
                    )
            }
        }
    }

    return dp[m][n]
}
```

### 复杂度

```text
时间：O(mn)
空间：O(mn)
```

### 易错点

子序列不要求连续。

## 89. 加油站

```js
                end - start + 1
            )

            start = i + 1
        }
    }

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(k)
```

### 易错点

当前分段结束的条件不是“当前字符最后一次出现”，而是：

```text
整个区间里所有字符的最远最后位置
```

## 91. 手写 debounce 防抖

### 题目

连续调用函数时：

```text
不断取消之前的定时器
只执行最后一次
```

典型场景：

```text
搜索框
input
resize
```

### JS 标准答案

```js
function debounce(fn, delay) {
    let timer = null

    return function (...args) {
        clearTimeout(timer)

        timer = setTimeout(() => {
            fn.apply(this, args)
        }, delay)
    }
}
```

### 复杂度

单次调用：

```text
时间：O(1)
空间：O(1)
```

### 面试追问

怎么支持立即执行？

可以增加：

```js
immediate
```

参数。

### 易错点

需要保留调用时的：

```js
this
args
```

因此通常：

```js
fn.apply(this, args)
```

而不是直接：

```js
fn(args)
```

## 92. 手写 throttle 节流

### 题目

在一段时间内最多执行一次。

### JS 标准答案

```js
function throttle(fn, delay) {
    let lastTime = 0

    return function (...args) {
        const now = Date.now()

        if (now - lastTime >= delay) {
            lastTime = now

            fn.apply(this, args)
        }
    }
}
```

### 复杂度

```text
单次调用：O(1)
```

### 面试追问

如何实现：

```text
leading
trailing
```

都支持的完整版？

可以增加 timer 和剩余时间判断。

### 易错点

不要把 debounce 与 throttle 混淆：

```text
debounce：最后一次
throttle：固定时间窗口最多一次
```

## 93. 手写 deepClone

### 题目

实现对象深拷贝，并处理：

```text
循环引用
Date
RegExp
Map
Set
```

### JS 标准答案

```js
function deepClone(value, seen = new WeakMap()) {
    if (
        value === null ||
        typeof value !== 'object'
    ) {
        return value
    }

    if (value instanceof Date) {
        return new Date(value)
    }

    if (value instanceof RegExp) {
        return new RegExp(
            value.source,
            value.flags
        )
    }

    if (seen.has(value)) {
        return seen.get(value)
    }

    if (value instanceof Map) {
        const result = new Map()

        seen.set(value, result)

        for (const [key, val] of value) {
            result.set(
                deepClone(key, seen),
                deepClone(val, seen)
            )
        }

        return result
    }

    if (value instanceof Set) {
        const result = new Set()

        seen.set(value, result)

        for (const item of value) {
            result.add(
                deepClone(item, seen)
            )
        }

        return result
    }

    const result =
        Array.isArray(value)
            ? []
            : Object.create(
                Object.getPrototypeOf(value)
            )

    seen.set(value, result)

    for (
        const key of Reflect.ownKeys(value)
    ) {
        result[key] =
            deepClone(
                value[key],
                seen
            )
    }

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(n)
```

### 面试追问

为什么使用：

```js
WeakMap
```

因为它可以记录已经克隆过的对象，解决循环引用。

例如：

```js
const obj = {}
obj.self = obj
```

### 易错点

简单的：

```js
JSON.parse(
    JSON.stringify(obj)
)
```

不能完整处理：

```text
undefined
Symbol
函数
Date
RegExp
Map
Set
循环引用
BigInt
```

## 94. 手写 EventEmitter

### 题目

实现：

```text
on
off
emit
once
```

### JS 标准答案

```js
class EventEmitter {
    constructor() {
        this.events = new Map()
    }

    on(event, listener) {
        if (!this.events.has(event)) {
            this.events.set(event, [])
        }

        this.events
            .get(event)
            .push(listener)
    }

    off(event, listener) {
        const listeners =
            this.events.get(event)

        if (!listeners) {
            return
        }

        this.events.set(
            event,
            listeners.filter(
                fn => fn !== listener
            )
        )
    }

    emit(event, ...args) {
        const listeners =
            this.events.get(event)

        if (!listeners) {
            return
        }

        for (const listener of listeners) {
            listener(...args)
        }
    }

    once(event, listener) {
        const wrapper = (...args) => {
            listener(...args)
            this.off(event, wrapper)
        }

        this.on(event, wrapper)
    }
}
```

### 复杂度

```text
on：O(1)
emit：O(n)
off：O(n)
```

### 面试追问

Vue、Node.js 中的事件系统和它有什么关系？

核心思想都是：

```text
事件名
→
监听器集合
→
触发监听器
```

### 易错点

`once` 注册的其实是包装函数，所以 `off` 时也需要删除包装函数。

## 95. 手写 Function.prototype.call

### 思路

`call` 本质：

```text
临时改变 this
立即执行
```

### JS 标准答案

```js
Function.prototype.myCall = function (
    context,
    ...args
) {
    const fn = this

    const target =
        context == null
            ? globalThis
            : Object(context)

    const key = Symbol('fn')

    target[key] = fn

    const result = target[key](...args)

    delete target[key]

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

为什么用：

```js
Symbol()
```

避免和对象已有属性冲突。

### 易错点

核心不是“调用函数”本身，而是：

```text
让函数以某个对象的方法形式执行
```

从而改变 `this`。

## 96. 手写 Function.prototype.apply

### 思路

和 `call` 基本一样，只不过参数来自一个数组。

### JS 标准答案

```js
Function.prototype.myApply = function (
    context,
    args
) {
    const fn = this

    const target =
        context == null
            ? globalThis
            : Object(context)

    const key = Symbol('fn')

    target[key] = fn

    const result =
        Array.isArray(args)
            ? target[key](...args)
            : target[key]()

    delete target[key]

    return result
}
```

### 复杂度

```text
时间：O(n)
空间：O(1)
```

### 面试追问

为什么：

```text
call(a,b,c)
apply(a,[b,c])
```

最核心的区别就是：

```text
call：参数列表
apply：参数数组
```

### 易错点

不要直接写：

```js
target[key](args)
```

那样会把整个数组作为一个参数传进去。

## 97. 手写 Function.prototype.bind

### 思路

`bind` 与 `call` 最大区别：

```text
call：立即执行
bind：返回一个新函数
```

### JS 标准答案

```js
Function.prototype.myBind = function (
    context,
    ...presetArgs
) {
    const fn = this

    function bound(...restArgs) {
        const isNew =
            this instanceof bound

        return fn.apply(
            isNew ? this : context,
            [
                ...presetArgs,
                ...restArgs
            ]
        )
    }

    bound.prototype =
        Object.create(fn.prototype)

    return bound
}
```

### 复杂度

创建绑定函数：

```text
O(1)
```

调用时参数复制：

```text
O(n)
```

### 面试追问

为什么要处理：

```js
new bound()
```

因为原生 `bind` 返回的函数仍然可以被 `new` 调用，此时需要忽略原来的 `context`。

### 易错点

最简单的 `bind` 手写题经常只实现普通函数调用，没有处理构造函数场景。

## 98. 手写 Curry 柯里化

### 题目

把：

```js
sum(1, 2, 3)
```

变成：

```js
sum(1)(2)(3)
```

### JS 标准答案

```js
function curry(fn) {
    return function curried(...args) {
        if (args.length >= fn.length) {
            return fn(...args)
        }

        return function (...nextArgs) {
            return curried(
                ...args,
                ...nextArgs
            )
        }
    }
}
```

使用：

```js
function sum(a, b, c) {
    return a + b + c
}

const add = curry(sum)

console.log(
    add(1)(2)(3)
)

console.log(
    add(1, 2)(3)
)

console.log(
    add(1)(2, 3)
)
```

### 复杂度

和调用次数以及参数数量有关。

### 面试追问

柯里化有什么工程意义？

可以用于：

```text
函数参数预配置
配置复用
函数组合
FP
```

### 易错点

核心不是递归，而是：

```text
闭包保存之前已经收集到的参数
```

## 99. Promise 并发控制

### 题目

有很多异步任务：

```js
const tasks = [
    () => fetch('/api/1'),
    () => fetch('/api/2'),
    () => fetch('/api/3'),
    () => fetch('/api/4'),
    () => fetch('/api/5')
]
```

要求：

```text
同时最多执行 2 个
```

### JS 标准答案

```js
async function promisePool(tasks, limit) {
    const results =
        new Array(tasks.length)

    let nextIndex = 0

    async function worker() {
        while (true) {
            const index = nextIndex++

            if (index >= tasks.length) {
                return
            }

            results[index] =
                await tasks[index]()
        }
    }

    const workers =
        Array.from(
            {
                length: Math.min(
                    limit,
                    tasks.length
                )
            },
            () => worker()
        )

    await Promise.all(workers)

    return results
}
```

### 复杂度

核心任务调度是：

```text
O(n)
```

总体耗时取决于任务执行时间和并发数。

### 面试追问

真实项目还需要考虑什么？

```text
失败重试
超时
取消
AbortController
任务优先级
失败是否继续
```

### 易错点

不要写成：

```js
await Promise.all(
    tasks.map(task => task())
)
```

因为这会一次性启动全部请求。

## 100. 手写 LRU Cache

**LeetCode 146**

### 题目

实现：

```text
get
put
```

并保证平均 O(1)。

### 思路

使用 JS `Map`：

```text
Map 保持插入顺序
```

访问一个 key 时：

```text
删除
重新插入
```

就可以把它移动到最新位置。

### JS 标准答案

```js
class LRUCache {
    constructor(capacity) {
        this.capacity = capacity
        this.cache = new Map()
    }

    get(key) {
        if (!this.cache.has(key)) {
            return -1
        }

        const value =
            this.cache.get(key)

        this.cache.delete(key)
        this.cache.set(key, value)

        return value
    }

    put(key, value) {
        if (this.cache.has(key)) {
            this.cache.delete(key)
        }

        this.cache.set(key, value)

        if (
            this.cache.size >
            this.capacity
        ) {
            const oldestKey =
                this.cache
                    .keys()
                    .next()
                    .value

            this.cache.delete(oldestKey)
        }
    }
}
```

### 复杂度

```text
get：平均 O(1)
put：平均 O(1)
空间：O(capacity)
```

### 面试追问

经典实现为什么通常是：

```text
HashMap + 双向链表
```

因为：

```text
HashMap：
O(1) 查找节点

双向链表：
O(1) 删除 / 插入节点
```

### 易错点

LRU 的核心不是“缓存”，而是：

```text
最近最少使用淘汰策略
```

要明确：

```text
访问一次
→ 变成最近使用
```
