### 01. 两数之和

难度：**简单**　|　[LeetCode 1](https://leetcode.cn/problems/two-sum/)

**题目**：给定整数数组 nums 和目标值 target，返回和为 target 的两个数的下标。

**思路**

- 暴力两层循环是 O(n²)，面试里说出来只能算起点。
- 用哈希表把「查找另一个数」的代价降到 O(1)：边遍历边把 `值 → 下标` 存进 Map，每到一个数先问「target 减它」有没有出现过。
- 只需要一次遍历，因为配对的两个数总有一个先被存进表里。

```js
function twoSum(nums, target) {
  const seen = new Map(); // 值 -> 下标
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
  return [];
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：用 Map 而不是普通对象：对象的键会被转成字符串，数组里出现 1 和 '1' 时会串味。

### 02. 有效的括号

难度：**简单**　|　[LeetCode 20](https://leetcode.cn/problems/valid-parentheses/)

**题目**：判断只包含 ()[]{} 的字符串是否合法闭合。

**思路**

- 左括号入栈，遇到右括号就弹出栈顶比对是否配对。
- 把右括号映射到它对应的左括号，省掉一堆 if-else。
- 结束时栈必须为空，否则说明有左括号没闭合。

```js
function isValid(s) {
  const pairs = { ')': '(', ']': '[', '}': '{' };
  const stack = [];
  for (const ch of s) {
    if (pairs[ch]) {
      if (stack.pop() !== pairs[ch]) return false; // 栈空时 pop 得到 undefined，同样不相等
    } else {
      stack.push(ch);
    }
  }
  return stack.length === 0;
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：两个常见漏判：栈提前空了（右括号多）、遍历完栈还有剩（左括号多）。

### 03. 移动零

难度：**简单**　|　[LeetCode 283](https://leetcode.cn/problems/move-zeroes/)

**题目**：原地把所有 0 移到末尾，保持非零元素的相对顺序。

**思路**

- 快慢指针：slow 指向下一个非零元素该放的位置，fast 负责扫描。
- fast 每遇到一个非零元素就和 slow 交换，交换保证了被换到后面的一定是 0。
- 不能先删再补，那样是 O(n²)。

```js
function moveZeroes(nums) {
  let slow = 0;
  for (let fast = 0; fast < nums.length; fast++) {
    if (nums[fast] !== 0) {
      [nums[slow], nums[fast]] = [nums[fast], nums[slow]];
      slow++;
    }
  }
  return nums;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：这道题的模板可以直接改成「原地移除所有等于 val 的元素」（LeetCode 27）。

### 04. 合并两个有序数组

难度：**简单**　|　[LeetCode 88](https://leetcode.cn/problems/merge-sorted-array/)

**题目**：nums1 后面留了 n 个空位，把 nums2 原地并进去并保持有序。

**思路**

- 从前往后合并会覆盖 nums1 还没读到的数据，所以要**从后往前**填。
- 三个指针：i 指 nums1 有效部分末尾，j 指 nums2 末尾，k 指总末尾，每次把较大的那个放到 k。
- j 走完就结束；i 先走完不用管，剩下的本来就在正确位置上。

```js
function merge(nums1, m, nums2, n) {
  let i = m - 1, j = n - 1, k = m + n - 1;
  while (j >= 0) {
    nums1[k--] = (i >= 0 && nums1[i] > nums2[j]) ? nums1[i--] : nums2[j--];
  }
  return nums1;
}
```

**复杂度**：时间 O(m+n)，空间 O(1)

### 05. 最长公共前缀

难度：**简单**　|　[LeetCode 14](https://leetcode.cn/problems/longest-common-prefix/)

**题目**：查找字符串数组中的最长公共前缀。

**思路**

- 纵向扫描：以第一个串为基准，逐列比较所有字符串的第 i 个字符。
- 一旦某个串长度不够或字符不同，就在这里截断返回。
- 比「先排序再比首尾」更直观，也不需要 O(n log n) 的排序开销。

```js
function longestCommonPrefix(strs) {
  if (!strs.length) return '';
  for (let i = 0; i < strs[0].length; i++) {
    const c = strs[0][i];
    for (let j = 1; j < strs.length; j++) {
      if (i === strs[j].length || strs[j][i] !== c) return strs[0].slice(0, i);
    }
  }
  return strs[0];
}
```

**复杂度**：时间 O(m·n)（m 为最短串长度），空间 O(1)

### 06. 买卖股票的最佳时机

难度：**简单**　|　[LeetCode 121](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

**题目**：只允许买卖一次，求最大利润。

**思路**

- 对每一天来说，最优解就是「今天的价格 − 之前出现过的最低价」。
- 一次遍历同时维护历史最低价和历史最大利润即可。
- 这其实是最大子数组和的变形：把价格差分之后就是题 35。

```js
function maxProfit(prices) {
  let min = Infinity, best = 0;
  for (const p of prices) {
    min = Math.min(min, p);
    best = Math.max(best, p - min);
  }
  return best;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：追问「可以交易多次」（LeetCode 122）时答案更简单：把所有上涨区间的涨幅加起来。

### 07. 数组扁平化、去重、排序

难度：**简单**　|　来源：前端高频手写

**题目**：把任意嵌套的数组拉平，去掉重复项，再升序排列。

**思路**

- 现代写法一行搞定，但面试官通常会追问「手写 flatten」。
- 递归版清晰，但层级极深时可能爆栈；迭代版用栈模拟，安全但需要最后 reverse。
- 去重用 Set；排序一定要传比较函数，`sort()` 默认按字符串字典序，会把 10 排到 2 前面。

```js
// 一行版（仅适合纯数字数组）
const flatUniqSort = arr => [...new Set(arr.flat(Infinity))].sort((a, b) => a - b);

// 手写 flatten：递归版，支持指定深度
function flatten(arr, depth = Infinity) {
  const res = [];
  const walk = (list, d) => {
    for (const item of list) {
      if (Array.isArray(item) && d > 0) walk(item, d - 1);
      else res.push(item);
    }
  };
  walk(arr, depth);
  return res;
}

// 手写 flatten：迭代版，不怕深层嵌套
function flattenIter(arr) {
  const stack = [...arr], res = [];
  while (stack.length) {
    const item = stack.pop();
    if (Array.isArray(item)) stack.push(...item);
    else res.push(item);
  }
  return res.reverse();
}
```

**复杂度**：时间 O(n log n)（瓶颈在排序），空间 O(n)

> ⚠️ **易错点**：被问到「reduce 版 flatten」时：`arr.reduce((a, b) => a.concat(Array.isArray(b) ? flatten(b) : b), [])`。

### 08. 螺旋矩阵

难度：**中等**　|　[LeetCode 54](https://leetcode.cn/problems/spiral-matrix/)

**题目**：按顺时针螺旋顺序返回矩阵中的所有元素。

**思路**

- 维护 top / bottom / left / right 四条边界，走完一条就把对应边界收缩一格。
- 四个方向依次是：左→右、上→下、右→左、下→上。
- 后两个方向必须加判断，否则单行或单列的矩阵会被重复读取。

```js
function spiralOrder(matrix) {
  if (!matrix.length) return [];
  let top = 0, bottom = matrix.length - 1;
  let left = 0, right = matrix[0].length - 1;
  const res = [];
  while (top <= bottom && left <= right) {
    for (let i = left; i <= right; i++) res.push(matrix[top][i]);
    top++;
    for (let i = top; i <= bottom; i++) res.push(matrix[i][right]);
    right--;
    if (top <= bottom) {
      for (let i = right; i >= left; i--) res.push(matrix[bottom][i]);
      bottom--;
    }
    if (left <= right) {
      for (let i = bottom; i >= top; i--) res.push(matrix[i][left]);
      left++;
    }
  }
  return res;
}
```

**复杂度**：时间 O(m·n)，空间 O(1)（不计结果）

> ⚠️ **易错点**：漏掉那两个 if 是最常见的错误，用 [[1,2,3]] 和 [[1],[2],[3]] 自测一下。

### 09. 反转链表

难度：**简单**　|　[LeetCode 206](https://leetcode.cn/problems/reverse-linked-list/)

**题目**：反转一个单链表并返回新的头节点。

**思路**

- 迭代版三个指针：prev、cur、next，把 cur.next 指回 prev 然后整体右移。
- 关键是先用 next 存住后继，否则改完指针就找不到路了。
- 递归版先反转后面的部分，再让 `head.next.next = head` 掉头，最后断开 `head.next`。

```js
// 迭代：推荐，面试首选
function reverseList(head) {
  let prev = null, cur = head;
  while (cur) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }
  return prev;
}

// 递归
function reverseListRec(head) {
  if (!head || !head.next) return head;
  const newHead = reverseListRec(head.next);
  head.next.next = head;
  head.next = null;   // 忘了这行会成环
  return newHead;
}
```

**复杂度**：迭代 时间 O(n) 空间 O(1)；递归 空间 O(n)

### 10. 合并两个有序链表

难度：**简单**　|　[LeetCode 21](https://leetcode.cn/problems/merge-two-sorted-lists/)

**题目**：把两个升序链表合并成一个新的升序链表。

**思路**

- 用 dummy 虚拟头节点，免去「第一个节点特殊处理」的判断。
- 每次取两个头中较小的接到 tail 后面，然后推进对应指针。
- 有一条走完后，把另一条整体接上即可。

```js
function mergeTwoLists(l1, l2) {
  const dummy = { val: 0, next: null };
  let tail = dummy;
  while (l1 && l2) {
    if (l1.val <= l2.val) { tail.next = l1; l1 = l1.next; }
    else { tail.next = l2; l2 = l2.next; }
    tail = tail.next;
  }
  tail.next = l1 || l2;
  return dummy.next;
}
```

**复杂度**：时间 O(m+n)，空间 O(1)

> ⚠️ **易错点**：dummy 头节点是链表题的通用技巧：删除节点、分割链表、K 个一组翻转都用得上。

### 11. 环形链表 II（找入环点）

难度：**中等**　|　[LeetCode 142](https://leetcode.cn/problems/linked-list-cycle-ii/)

**题目**：判断链表是否有环，有的话返回入环的第一个节点。

**思路**

- 快慢指针，快的一次两步。有环必相遇，无环快指针先到 null。
- 设头到入环点距离 a，入环点到相遇点 b，相遇点回到入环点 c。相遇时慢走了 a+b，快走了 a+b+b+c，且快是慢的两倍，推出 `a = c`。
- 所以相遇后让一个指针从头出发、另一个从相遇点出发，同速前进，再次相遇处就是入环点。

```js
function detectCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;
    fast = fast.next.next;
    if (slow === fast) {              // 相遇，说明有环
      let p = head;
      while (p !== slow) { p = p.next; slow = slow.next; }
      return p;                       // 入环点
    }
  }
  return null;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：只判断有没有环（LeetCode 141）就把相遇后那段删掉直接 return true。

### 12. LRU 缓存

难度：**中等**　|　[LeetCode 146](https://leetcode.cn/problems/lru-cache/)

**题目**：设计一个支持 get / put 的固定容量缓存，容量满时淘汰最久未使用的键。

**思路**

- 标准解法是「哈希表 + 双向链表」：哈希表保证 O(1) 定位，链表维护使用顺序。
- JS 里有捷径：`Map` 本身按插入顺序迭代，删掉再插入就等于把键移到最新位置。
- 淘汰时取 `map.keys().next().value` 拿到最老的键。
- 面试时最好先讲哈希 + 双链表的原理，再说「JS 的 Map 已经内置了这个有序性」。

```js
class LRUCache {
  constructor(capacity) {
    this.cap = capacity;
    this.map = new Map();
  }
  get(key) {
    if (!this.map.has(key)) return -1;
    const val = this.map.get(key);
    this.map.delete(key);      // 删除 + 重新插入 = 移到队尾（最新）
    this.map.set(key, val);
    return val;
  }
  put(key, value) {
    if (this.map.has(key)) this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.cap) {
      this.map.delete(this.map.keys().next().value); // 淘汰最老的键
    }
  }
}
```

**复杂度**：get / put 均为 O(1)，空间 O(capacity)

> ⚠️ **易错点**：前端场景很实际：图片缓存、接口结果缓存、keep-alive 的组件缓存都是这个模型。

### 13. K 个一组翻转链表

难度：**困难**　|　[LeetCode 25](https://leetcode.cn/problems/reverse-nodes-in-k-group/)

**题目**：每 k 个节点一组进行翻转，不足 k 个的部分保持原有顺序。

**思路**

- 先往前走 k 步确认这一组是否够数，不够就原样返回。
- 够数时，先递归处理后面的链表，拿到「已翻转好的后半段头节点」作为 prev。
- 再把当前这 k 个节点依次头插到 prev 前面，返回值自然就是本组翻转后的新头。

```js
function reverseKGroup(head, k) {
  let node = head;
  for (let i = 0; i < k; i++) {
    if (!node) return head;   // 不足 k 个，保持原样
    node = node.next;
  }
  // node 现在是下一组的头，先把后面的处理好
  let prev = reverseKGroup(node, k);
  let cur = head;
  for (let i = 0; i < k; i++) {
    const next = cur.next;
    cur.next = prev;
    prev = cur;
    cur = next;
  }
  return prev;  // 本组翻转后的新头
}
```

**复杂度**：时间 O(n)，空间 O(n/k)（递归栈）

> ⚠️ **易错点**：面试官常追问迭代版本以做到 O(1) 空间：用 dummy + groupPrev 指针，每组翻转后重新接线。

### 14. 最小栈

难度：**中等**　|　[LeetCode 155](https://leetcode.cn/problems/min-stack/)

**题目**：设计一个栈，支持 push / pop / top，并能在常数时间内取出最小元素。

**思路**

- 再开一个辅助栈，与主栈同步入栈出栈，存的是「当前位置的历史最小值」。
- push 时存 `min(新值, 当前最小)`，pop 时两个栈一起弹。
- 这样任何时刻辅助栈顶就是当前最小值。

```js
class MinStack {
  constructor() {
    this.stack = [];
    this.mins = [];
  }
  push(x) {
    this.stack.push(x);
    this.mins.push(this.mins.length ? Math.min(x, this.getMin()) : x);
  }
  pop() {
    this.mins.pop();
    return this.stack.pop();
  }
  top() { return this.stack[this.stack.length - 1]; }
  getMin() { return this.mins[this.mins.length - 1]; }
}
```

**复杂度**：所有操作 O(1)，空间 O(n)

> ⚠️ **易错点**：省空间的写法：辅助栈只在「新值 ≤ 当前最小」时入栈，但 pop 时要判断是否同步弹出。

### 15. 字符串解码

难度：**中等**　|　[LeetCode 394](https://leetcode.cn/problems/decode-string/)

**题目**：把形如 3[a2[c]] 的编码串还原成 accaccacc。

**思路**

- 嵌套结构 = 栈。准备两个栈，一个存重复次数，一个存「进入括号前已经拼好的字符串」。
- 遇到数字累积多位数（可能是 12[...]）；遇到 `[` 把当前状态压栈并清零。
- 遇到 `]` 弹出，拼成 `上层字符串 + 当前串.repeat(次数)`。

```js
function decodeString(s) {
  const numStack = [], strStack = [];
  let num = 0, cur = '';
  for (const ch of s) {
    if (ch >= '0' && ch <= '9') {
      num = num * 10 + Number(ch);          // 处理多位数
    } else if (ch === '[') {
      numStack.push(num);
      strStack.push(cur);
      num = 0;
      cur = '';
    } else if (ch === ']') {
      cur = strStack.pop() + cur.repeat(numStack.pop());
    } else {
      cur += ch;
    }
  }
  return cur;
}
```

**复杂度**：时间 O(n · 最大重复次数)，空间 O(n)

### 16. 每日温度（单调栈）

难度：**中等**　|　[LeetCode 739](https://leetcode.cn/problems/daily-temperatures/)

**题目**：对每一天，求还要等几天才会出现更高的温度。

**思路**

- 「下一个更大元素」这类问题的固定答案是单调递减栈，栈里存下标。
- 新元素比栈顶大时，说明栈顶那天的答案找到了，弹出并计算下标差。
- 每个下标最多进栈出栈一次，所以整体是 O(n)。

```js
function dailyTemperatures(temperatures) {
  const res = new Array(temperatures.length).fill(0);
  const stack = [];  // 存下标，对应温度单调递减
  for (let i = 0; i < temperatures.length; i++) {
    while (stack.length && temperatures[i] > temperatures[stack[stack.length - 1]]) {
      const j = stack.pop();
      res[j] = i - j;
    }
    stack.push(i);
  }
  return res;  // 栈里剩下的天数没有更高温，保持 0
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：同一模板可解：下一个更大元素 I/II、柱状图中最大的矩形、接雨水（单调栈解法）。

## 四、双指针与滑动窗口

> 把 O(n²) 降到 O(n) 的主力手段

### 17. 无重复字符的最长子串

难度：**中等**　|　[LeetCode 3](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

**题目**：找出不含重复字符的最长连续子串的长度。

**思路**

- 滑动窗口：right 不断右扩，出现重复就把 left 跳到「上次出现位置 + 1」。
- 用 Map 记录每个字符最后出现的下标，这样 left 可以一步到位而不是逐格挪。
- 判断时要加 `last.get(c) >= left`，因为记录的位置可能已经被甩在窗口左边了。

```js
function lengthOfLongestSubstring(s) {
  const last = new Map();      // 字符 -> 最后出现的下标
  let left = 0, best = 0;
  for (let right = 0; right < s.length; right++) {
    const c = s[right];
    if (last.has(c) && last.get(c) >= left) {
      left = last.get(c) + 1;  // 窗口左边界直接跳过去
    }
    last.set(c, right);
    best = Math.max(best, right - left + 1);
  }
  return best;
}
```

**复杂度**：时间 O(n)，空间 O(min(n, 字符集大小))

> ⚠️ **易错点**：用 abba 自测：走到第二个 a 时，若漏了 >= left 的判断，left 会被错误地回退。

### 18. 盛最多水的容器

难度：**中等**　|　[LeetCode 11](https://leetcode.cn/problems/container-with-most-water/)

**题目**：选两条垂线与 x 轴构成容器，求能装的最多的水。

**思路**

- 面积 = `min(左高, 右高) × 宽度`，左右指针从两端往中间收。
- 移动哪一边？移动较高的那边，宽度变小而高度不可能变大，一定更差；所以每次移动较矮的一边。
- 这个「排除法」的论证是本题的考点，写出代码不难，讲清楚为什么才是加分项。

```js
function maxArea(height) {
  let l = 0, r = height.length - 1, best = 0;
  while (l < r) {
    best = Math.max(best, Math.min(height[l], height[r]) * (r - l));
    if (height[l] < height[r]) l++;
    else r--;
  }
  return best;
}
```

**复杂度**：时间 O(n)，空间 O(1)

### 19. 三数之和

难度：**中等**　|　[LeetCode 15](https://leetcode.cn/problems/3sum/)

**题目**：找出数组中所有和为 0 且不重复的三元组。

**思路**

- 先排序，然后固定第一个数，剩下的退化成「有序数组里找两数之和」，用左右指针夹逼。
- 去重是本题真正的难点：第一层遇到与前一个相同的数直接跳过；命中答案后左右指针也要跳过相同值。
- 排序后若第一个数已经大于 0，后面不可能凑出 0，可以直接 break 剪枝。

```js
function threeSum(nums) {
  nums.sort((a, b) => a - b);
  const res = [];
  for (let i = 0; i < nums.length - 2; i++) {
    if (nums[i] > 0) break;                          // 剪枝
    if (i > 0 && nums[i] === nums[i - 1]) continue;  // 第一层去重
    let l = i + 1, r = nums.length - 1;
    while (l < r) {
      const sum = nums[i] + nums[l] + nums[r];
      if (sum === 0) {
        res.push([nums[i], nums[l], nums[r]]);
        while (l < r && nums[l] === nums[l + 1]) l++;  // 跳过重复
        while (l < r && nums[r] === nums[r - 1]) r--;
        l++; r--;
      } else if (sum < 0) {
        l++;
      } else {
        r--;
      }
    }
  }
  return res;
}
```

**复杂度**：时间 O(n²)，空间 O(log n)（排序栈）

> ⚠️ **易错点**：去重一定要用 `nums[i] === nums[i-1]` 而不是 `nums[i] === nums[i+1]`，后者会漏掉像 [-1,-1,2] 这样的合法答案。

### 20. 接雨水

难度：**困难**　|　[LeetCode 42](https://leetcode.cn/problems/trapping-rain-water/)

**题目**：给定柱状高度图，计算下雨后能接多少水。

**思路**

- 关键认知：每一格能接的水 = `min(左边最高, 右边最高) − 当前高度`。
- 朴素做法是预处理两个前缀最大值数组，O(n) 空间。
- 双指针优化：左右各维护一个已见最大值，哪边的最大值小就结算哪边——因为那一侧的短板已经确定，另一侧不管多高都不影响结果。

```js
function trap(height) {
  let l = 0, r = height.length - 1;
  let leftMax = 0, rightMax = 0, res = 0;
  while (l < r) {
    leftMax = Math.max(leftMax, height[l]);
    rightMax = Math.max(rightMax, height[r]);
    if (leftMax < rightMax) res += leftMax - height[l++];
    else res += rightMax - height[r--];
  }
  return res;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：还有单调递减栈的解法：按「层」横向计算积水，可以顺带复习题 16 的模板。

### 21. 最小覆盖子串

难度：**困难**　|　[LeetCode 76](https://leetcode.cn/problems/minimum-window-substring/)

**题目**：在 s 中找出涵盖 t 所有字符（含重复次数）的最短子串。

**思路**

- 滑动窗口的终极形态：右指针扩张直到窗口覆盖 t，再收缩左指针直到刚好不覆盖，过程中记录最短。
- 用一个 need 计数表 + 一个 missing 计数器判断是否覆盖，比每次遍历整个表快得多。
- need 的值可以变成负数，表示窗口里这个字符是多余的，收缩时正好利用这一点。

```js
function minWindow(s, t) {
  const need = new Map();
  for (const c of t) need.set(c, (need.get(c) || 0) + 1);

  let missing = t.length;         // 还差多少个字符才算覆盖
  let left = 0, start = 0, len = Infinity;

  for (let right = 0; right < s.length; right++) {
    const c = s[right];
    if (need.get(c) > 0) missing--;          // 这个字符是真正需要的
    need.set(c, (need.get(c) || 0) - 1);

    while (missing === 0) {                  // 已覆盖，尝试收缩
      if (right - left + 1 < len) {
        len = right - left + 1;
        start = left;
      }
      const lc = s[left++];
      need.set(lc, need.get(lc) + 1);
      if (need.get(lc) > 0) missing++;       // 弹出的是必需字符，窗口不再覆盖
    }
  }
  return len === Infinity ? '' : s.slice(start, start + len);
}
```

**复杂度**：时间 O(|s| + |t|)，空间 O(字符集大小)

### 23. 二叉树的中序遍历（迭代）

难度：**简单**　|　[LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/)

**题目**：不用递归，输出二叉树的中序遍历序列。

**思路**

- 用栈模拟递归：一路向左把节点压栈，到底后弹出访问，再转向右子树。
- 循环条件是「当前节点非空 或 栈非空」，缺一不可。
- 中序遍历二叉搜索树会得到升序序列，很多 BST 题的验证都基于这一点。

```js
function inorderTraversal(root) {
  const res = [], stack = [];
  let cur = root;
  while (cur || stack.length) {
    while (cur) {           // 一路向左
      stack.push(cur);
      cur = cur.left;
    }
    cur = stack.pop();      // 左边到头，访问自己
    res.push(cur.val);
    cur = cur.right;        // 转向右子树
  }
  return res;
}
```

**复杂度**：时间 O(n)，空间 O(h)

### 24. 二叉树的层序遍历

难度：**中等**　|　[LeetCode 102](https://leetcode.cn/problems/binary-tree-level-order-traversal/)

**题目**：按层返回节点值，每层一个数组。

**思路**

- BFS 队列，关键在于「分层」：进入循环时先记下当前队列长度，这一批就是一层。
- JS 里用两个数组（当前层 / 下一层）交替比 `shift()` 更快，因为 shift 是 O(n)。
- 前端里的树形组件、菜单渲染基本都是这个遍历模式。

```js
function levelOrder(root) {
  if (!root) return [];
  const res = [];
  let queue = [root];
  while (queue.length) {
    const level = [], next = [];
    for (const node of queue) {
      level.push(node.val);
      if (node.left) next.push(node.left);
      if (node.right) next.push(node.right);
    }
    res.push(level);
    queue = next;
  }
  return res;
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：锯齿形层序遍历（LeetCode 103）只要在偶数层把 level 反转一下。

### 25. 二叉树的右视图

难度：**中等**　|　[LeetCode 199](https://leetcode.cn/problems/binary-tree-right-side-view/)

**题目**：站在树的右侧，返回从上到下能看到的节点值。

**思路**

- BFS 解法：层序遍历，每层取最后一个。
- DFS 解法更巧：按「根 → 右 → 左」的顺序遍历，每个深度第一次被访问到的节点就是该层最右侧的。
- 用 `depth === res.length` 判断是不是第一次到这一层，省掉额外的 visited 结构。

```js
function rightSideView(root) {
  const res = [];
  const dfs = (node, depth) => {
    if (!node) return;
    if (depth === res.length) res.push(node.val); // 该深度第一次到达
    dfs(node.right, depth + 1);                   // 先右后左
    dfs(node.left, depth + 1);
  };
  dfs(root, 0);
  return res;
}
```

**复杂度**：时间 O(n)，空间 O(h)

### 26. 二叉树的最近公共祖先

难度：**中等**　|　[LeetCode 236](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

**题目**：找出两个给定节点的最近公共祖先。

**思路**

- 后序遍历。函数语义定义为：在以 root 为根的子树里，如果找到了 p 或 q 就返回它，否则返回 null。
- 左右子树各返回一个结果：两边都非空说明 p、q 分居两侧，当前节点就是答案。
- 只有一边非空就把它往上传，表示「这一侧找到了至少一个」。

```js
function lowestCommonAncestor(root, p, q) {
  if (!root || root === p || root === q) return root;
  const left = lowestCommonAncestor(root.left, p, q);
  const right = lowestCommonAncestor(root.right, p, q);
  if (left && right) return root;   // p、q 分别在两侧
  return left || right;             // 否则把非空的那侧往上传
}
```

**复杂度**：时间 O(n)，空间 O(h)

> ⚠️ **易错点**：如果是二叉搜索树（LeetCode 235），可以利用大小关系直接从根往下走，O(h) 且无需递归。

### 27. 从前序与中序遍历构造二叉树

难度：**中等**　|　[LeetCode 105](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

**题目**：根据前序和中序遍历结果重建二叉树。

**思路**

- 前序的第一个元素是根；在中序里找到它，左边是左子树、右边是右子树。
- 递归处理时不切数组，只传下标区间，避免大量 slice 拷贝。
- 用 Map 预存中序里「值 → 下标」，把每次查找从 O(n) 降到 O(1)。

```js
function buildTree(preorder, inorder) {
  const idx = new Map();
  inorder.forEach((v, i) => idx.set(v, i));

  let pre = 0;  // 前序指针，按前序顺序消费根节点
  const build = (l, r) => {          // 中序区间 [l, r]
    if (l > r) return null;
    const val = preorder[pre++];
    const node = { val, left: null, right: null };
    const m = idx.get(val);
    node.left = build(l, m - 1);
    node.right = build(m + 1, r);    // 顺序不能换，前序是「根左右」
    return node;
  };
  return build(0, inorder.length - 1);
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：left 一定要先于 right 构建，因为 pre 指针是按前序顺序自增的。

## 六、排序与二分

> 手写排序几乎必考，二分的坑全在边界

### 28. 手写快速排序与归并排序

难度：**中等**　|　来源：面试必考

**题目**：手写两种经典 O(n log n) 排序，并说明稳定性与适用场景。

**思路**

- 快排：选基准 → 分区 → 递归两侧。原地排序，空间省，但不稳定，最坏 O(n²)。
- 随机选基准可以有效避免「已经有序的数组」触发最坏情况。
- 归并：分到底再两两合并。稳定，最坏也是 O(n log n)，代价是 O(n) 额外空间。
- V8 的 `Array.prototype.sort` 用的是 TimSort（归并 + 插入排序的混合），保证稳定。

```js
// —— 快速排序（原地）——
function quickSort(arr, l = 0, r = arr.length - 1) {
  if (l >= r) return arr;
  const p = partition(arr, l, r);
  quickSort(arr, l, p - 1);
  quickSort(arr, p + 1, r);
  return arr;
}

function partition(arr, l, r) {
  const rand = l + Math.floor(Math.random() * (r - l + 1)); // 随机基准
  [arr[rand], arr[r]] = [arr[r], arr[rand]];
  const pivot = arr[r];
  let i = l;
  for (let j = l; j < r; j++) {
    if (arr[j] < pivot) {
      [arr[i], arr[j]] = [arr[j], arr[i]];
      i++;
    }
  }
  [arr[i], arr[r]] = [arr[r], arr[i]];
  return i;   // 基准最终所在位置
}

// —— 归并排序 ——
function mergeSort(arr) {
  if (arr.length < 2) return arr;
  const mid = arr.length >> 1;
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));
  const res = [];
  let i = 0, j = 0;
  while (i < left.length && j < right.length) {
    res.push(left[i] <= right[j] ? left[i++] : right[j++]);  // <= 保证稳定
  }
  return res.concat(left.slice(i), right.slice(j));
}
```

**复杂度**：平均 O(n log n)；快排空间 O(log n)，归并空间 O(n)

> ⚠️ **易错点**：别写「用 filter 分成三份再 concat」的快排，那是 O(n) 额外空间，面试官一眼看出你没理解原地分区。

### 29. 合并区间

难度：**中等**　|　[LeetCode 56](https://leetcode.cn/problems/merge-intervals/)

**题目**：合并所有重叠的区间。

**思路**

- 先按起点排序，之后只需要和结果里的最后一个区间比较。
- 如果当前起点 ≤ 上一个区间的终点，说明重叠，把终点取两者最大值。
- 否则直接作为新区间推入结果。

```js
function merge(intervals) {
  intervals.sort((a, b) => a[0] - b[0]);
  const res = [];
  for (const [s, e] of intervals) {
    const last = res[res.length - 1];
    if (last && s <= last[1]) last[1] = Math.max(last[1], e);
    else res.push([s, e]);
  }
  return res;
}
```

**复杂度**：时间 O(n log n)，空间 O(n)

> ⚠️ **易错点**：终点要取 max：[1,10] 和 [2,3] 合并后仍是 [1,10]，直接赋值会出错。

### 30. 搜索旋转排序数组

难度：**中等**　|　[LeetCode 33](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

**题目**：在一个被旋转过的升序数组中查找目标值，要求 O(log n)。

**思路**

- 旋转后数组从中点切开，必有一半是完全有序的。
- 先判断哪半边有序（比较 `nums[l]` 和 `nums[mid]`），再看 target 是否落在那个有序区间内。
- 落在里面就往这半边收，否则去另一半。

```js
function search(nums, target) {
  let l = 0, r = nums.length - 1;
  while (l <= r) {
    const mid = (l + r) >> 1;
    if (nums[mid] === target) return mid;
    if (nums[l] <= nums[mid]) {              // 左半有序
      if (nums[l] <= target && target < nums[mid]) r = mid - 1;
      else l = mid + 1;
    } else {                                 // 右半有序
      if (nums[mid] < target && target <= nums[r]) l = mid + 1;
      else r = mid - 1;
    }
  }
  return -1;
}
```

**复杂度**：时间 O(log n)，空间 O(1)

> ⚠️ **易错点**：`nums[l] <= nums[mid]` 的等号不能少，否则只剩两个元素时会判错。

### 31. 数组中的第 K 个最大元素

难度：**中等**　|　[LeetCode 215](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

**题目**：在未排序的数组中找到第 k 个最大的元素。

**思路**

- 直接排序是 O(n log n)，能过但不是考点。
- 快速选择：借用快排的 partition，但只递归包含目标下标的那一侧，平均 O(n)。
- 第 k 大在升序数组中的下标是 `n − k`，转换好这个下标本题就完成一半。
- 另一种标准解法是维护大小为 k 的小顶堆，时间 O(n log k)，适合海量数据流场景。

```js
function findKthLargest(nums, k) {
  const target = nums.length - k;   // 升序下标
  let l = 0, r = nums.length - 1;
  while (true) {
    const p = partition(nums, l, r);   // 复用题 28 的 partition
    if (p === target) return nums[p];
    if (p < target) l = p + 1;
    else r = p - 1;
  }
}
```

**复杂度**：平均 O(n)，最坏 O(n²)（随机基准后概率极低），空间 O(1)

### 32. 全排列

难度：**中等**　|　[LeetCode 46](https://leetcode.cn/problems/permutations/)

**题目**：返回不含重复数字的数组的所有可能排列。

**思路**

- 回溯模板：做选择 → 递归 → 撤销选择。
- 用 used 数组标记哪些元素已经在路径里，避免重复使用。
- 收集答案时必须 `[...path]` 做一次拷贝，直接 push 引用会被后续的 pop 改掉。

```js
function permute(nums) {
  const res = [], path = [];
  const used = new Array(nums.length).fill(false);

  const backtrack = () => {
    if (path.length === nums.length) {
      res.push([...path]);   // 必须拷贝
      return;
    }
    for (let i = 0; i < nums.length; i++) {
      if (used[i]) continue;
      used[i] = true;
      path.push(nums[i]);
      backtrack();
      path.pop();            // 撤销选择
      used[i] = false;
    }
  };

  backtrack();
  return res;
}
```

**复杂度**：时间 O(n · n!)，空间 O(n)

> ⚠️ **易错点**：含重复数字时（LeetCode 47）先排序，再加剪枝：`i > 0 && nums[i] === nums[i-1] && !used[i-1]` 时跳过。

### 33. 岛屿数量

难度：**中等**　|　[LeetCode 200](https://leetcode.cn/problems/number-of-islands/)

**题目**：统计二维网格中由 '1' 组成的岛屿数量。

**思路**

- 遍历每个格子，遇到陆地就计数加一，然后用 DFS「淹没」整座岛，防止重复统计。
- 淹没就是把访问过的 '1' 直接改成 '0'，省掉一个 visited 数组。
- 越界和非陆地的判断放在递归入口统一处理，代码最简洁。

```js
function numIslands(grid) {
  if (!grid.length) return 0;
  const rows = grid.length, cols = grid[0].length;
  let count = 0;

  const sink = (r, c) => {
    if (r < 0 || c < 0 || r >= rows || c >= cols || grid[r][c] !== '1') return;
    grid[r][c] = '0';          // 标记为已访问
    sink(r + 1, c); sink(r - 1, c);
    sink(r, c + 1); sink(r, c - 1);
  };

  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (grid[r][c] === '1') { count++; sink(r, c); }
    }
  }
  return count;
}
```

**复杂度**：时间 O(m·n)，空间 O(m·n)（最坏递归深度）

> ⚠️ **易错点**：网格特别大时递归会爆栈，改成显式栈的迭代 DFS 或 BFS 队列。

### 34. 爬楼梯

难度：**简单**　|　[LeetCode 70](https://leetcode.cn/problems/climbing-stairs/)

**题目**：每次可以爬 1 或 2 个台阶，问爬到第 n 阶有多少种方法。

**思路**

- 到第 n 阶只能从 n−1 或 n−2 上来，所以 `f(n) = f(n−1) + f(n−2)`，就是斐波那契。
- 只依赖前两个状态，用两个变量滚动即可，不需要整个 dp 数组。
- 这是理解「状态定义 + 转移方程」最好的入门题。

```js
function climbStairs(n) {
  let prev = 1, cur = 1;   // f(0)=1, f(1)=1
  for (let i = 2; i <= n; i++) {
    [prev, cur] = [cur, prev + cur];
  }
  return cur;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：递归写法一定要加记忆化，否则 n=45 就会超时。

### 35. 最大子数组和

难度：**中等**　|　[LeetCode 53](https://leetcode.cn/problems/maximum-subarray/)

**题目**：找出具有最大和的连续子数组，返回其和。

**思路**

- 状态定义：`cur` 表示以当前元素结尾的最大子数组和。
- 转移：要么把前面的接上，要么从自己重新开始——`cur = max(nums[i], cur + nums[i])`。
- 换句话说，只要前面的累计是负数，就该丢掉重来。

```js
function maxSubArray(nums) {
  let cur = nums[0], best = nums[0];
  for (let i = 1; i < nums.length; i++) {
    cur = Math.max(nums[i], cur + nums[i]);
    best = Math.max(best, cur);
  }
  return best;
}
```

**复杂度**：时间 O(n)，空间 O(1)

> ⚠️ **易错点**：best 要初始化成 nums[0] 而不是 0，否则全是负数的用例会返回 0。

### 36. 零钱兑换

难度：**中等**　|　[LeetCode 322](https://leetcode.cn/problems/coin-change/)

**题目**：用给定面额凑出总金额，求最少需要几枚硬币，凑不出返回 -1。

**思路**

- 完全背包的最值问题。`dp[i]` = 凑出金额 i 所需的最少硬币数。
- 转移：对每个面额 c，`dp[i] = min(dp[i], dp[i−c] + 1)`。
- 初始值 `dp[0] = 0`，其余设为 Infinity 表示暂时凑不出。
- 注意贪心（每次拿最大面额）是错的，比如 coins=[1,3,4]、amount=6。

```js
function coinChange(coins, amount) {
  const dp = new Array(amount + 1).fill(Infinity);
  dp[0] = 0;
  for (let i = 1; i <= amount; i++) {
    for (const c of coins) {
      if (c <= i) dp[i] = Math.min(dp[i], dp[i - c] + 1);
    }
  }
  return dp[amount] === Infinity ? -1 : dp[amount];
}
```

**复杂度**：时间 O(amount × 硬币种类)，空间 O(amount)

### 37. 最长递增子序列

难度：**中等**　|　[LeetCode 300](https://leetcode.cn/problems/longest-increasing-subsequence/)

**题目**：求严格递增子序列的最大长度（子序列可以不连续）。

**思路**

- O(n²) 版：`dp[i]` = 以 nums[i] 结尾的最长递增子序列长度，向前找所有比它小的取最大。
- O(n log n) 版：维护 tails 数组，`tails[k]` 表示长度为 k+1 的递增子序列可能的最小结尾。
- 每来一个数，用二分找到第一个 ≥ 它的位置替换掉；找不到就追加。tails 的长度就是答案。
- 注意 tails 本身不是某个真实的子序列，只是用来做长度统计的辅助结构。

```js
// O(n²) 版：思路直观，先讲这个
function lengthOfLIS(nums) {
  if (!nums.length) return 0;
  const dp = new Array(nums.length).fill(1);
  let best = 1;
  for (let i = 1; i < nums.length; i++) {
    for (let j = 0; j < i; j++) {
      if (nums[j] < nums[i]) dp[i] = Math.max(dp[i], dp[j] + 1);
    }
    best = Math.max(best, dp[i]);
  }
  return best;
}

// O(n log n) 版：贪心 + 二分
function lengthOfLISFast(nums) {
  const tails = [];
  for (const x of nums) {
    let l = 0, r = tails.length;
    while (l < r) {                       // 找第一个 >= x 的位置
      const mid = (l + r) >> 1;
      if (tails[mid] < x) l = mid + 1;
      else r = mid;
    }
    tails[l] = x;                         // 越界即追加
  }
  return tails.length;
}
```

**复杂度**：O(n²) / O(n log n)，空间均为 O(n)

> ⚠️ **易错点**：Vue 3 的 diff 算法里就用了这个 O(n log n) 版本来求最长稳定子序列，尽量减少 DOM 移动。

### 38. 编辑距离

难度：**困难**　|　[LeetCode 72](https://leetcode.cn/problems/edit-distance/)

**题目**：求把 word1 转成 word2 所需的最少操作数（插入、删除、替换）。

**思路**

- 二维 DP：`dp[i][j]` = word1 前 i 个字符转成 word2 前 j 个字符的最少操作数。
- 字符相同时不用操作，直接继承 `dp[i−1][j−1]`。
- 不同时取三种操作的最小值再加一：替换 `dp[i−1][j−1]`、删除 `dp[i−1][j]`、插入 `dp[i][j−1]`。
- 边界：一方为空串时，操作数就是另一方的长度。

```js
function minDistance(word1, word2) {
  const m = word1.length, n = word2.length;
  // dp[i][0] = i（全删），dp[0][j] = j（全插）
  const dp = Array.from({ length: m + 1 }, (_, i) =>
    Array.from({ length: n + 1 }, (_, j) => (i === 0 ? j : j === 0 ? i : 0))
  );

  for (let i = 1; i <= m; i++) {
    for (let j = 1; j <= n; j++) {
      dp[i][j] = word1[i - 1] === word2[j - 1]
        ? dp[i - 1][j - 1]
        : 1 + Math.min(
            dp[i - 1][j - 1],  // 替换
            dp[i - 1][j],      // 删除
            dp[i][j - 1]       // 插入
          );
    }
  }
  return dp[m][n];
}
```

**复杂度**：时间 O(m·n)，空间 O(m·n)（可用滚动数组压到 O(n)）

> ⚠️ **易错点**：同一套框架可解：最长公共子序列、最长公共子串、正则匹配。

### 39. 手写 Promise.all 与并发限制调度器

难度：**困难**　|　来源：前端必考

**题目**：实现 Promise.all，并写一个「同时最多跑 N 个异步任务」的调度器。

**思路**

- Promise.all：结果按**原下标**写入，不能按完成顺序 push；用计数器判断是否全部完成。
- 空数组要立刻 resolve；非 Promise 的值要用 `Promise.resolve()` 包一层。
- 任何一个 reject 就整体 reject，所以 reject 可以直接作为 then 的第二个参数。
- 并发调度器：先启动 limit 个任务，每完成一个就补一个，用游标 next 保证任务不被重复领取。
- 这道题在前端场景里非常实际：批量上传、批量请求接口都要限流，避免打爆浏览器的并发连接数。

```js
// —— 手写 Promise.all ——
function myPromiseAll(iterable) {
  return new Promise((resolve, reject) => {
    const items = Array.from(iterable);
    const res = new Array(items.length);
    let done = 0;
    if (items.length === 0) return resolve(res);

    items.forEach((item, i) => {
      Promise.resolve(item).then(
        value => {
          res[i] = value;                       // 按下标填，保证顺序
          if (++done === items.length) resolve(res);
        },
        reject                                  // 一个失败，整体失败
      );
    });
  });
}

// —— 并发限制调度器 ——
// tasks: 返回 Promise 的函数数组；limit: 最大并发数
function limitConcurrency(tasks, limit) {
  return new Promise(resolve => {
    const results = new Array(tasks.length);
    let next = 0, done = 0;
    if (!tasks.length) return resolve(results);

    const run = () => {
      const i = next++;
      if (i >= tasks.length) return;
      Promise.resolve()
        .then(tasks[i])
        .then(
          value  => (results[i] = { status: 'fulfilled', value }),
          reason => (results[i] = { status: 'rejected', reason })
        )
        .then(() => {
          if (++done === tasks.length) resolve(results);
          else run();                           // 空出一个坑位就补一个
        });
    };

    for (let i = 0; i < Math.min(limit, tasks.length); i++) run();
  });
}
```

**复杂度**：并发数始终不超过 limit，总耗时接近最优

> ⚠️ **易错点**：tasks 里存的必须是「返回 Promise 的函数」而不是 Promise 实例——Promise 一创建就开始执行了，根本限不住并发。

### 40. 防抖与节流

难度：**中等**　|　来源：前端必考

**题目**：手写 debounce 和 throttle，并说清两者的区别与适用场景。

**思路**

- 防抖：事件停止触发 wait 毫秒后才执行一次。适合搜索联想、表单校验、resize 结束后重算布局。
- 节流：无论触发多频繁，每 wait 毫秒最多执行一次。适合滚动加载、拖拽、高频上报。
- 两者都要用 `fn.apply(this, args)` 透传 this 和参数，这是面试官重点看的细节。
- 加分项：提供 cancel 方法，以及防抖的 immediate（首次立即执行）选项。

```js
function debounce(fn, wait = 300, immediate = false) {
  let timer = null;
  function debounced(...args) {
    const callNow = immediate && !timer;
    if (timer) clearTimeout(timer);
    if (callNow) fn.apply(this, args);
    timer = setTimeout(() => {
      timer = null;
      if (!immediate) fn.apply(this, args);
    }, wait);
  }
  debounced.cancel = () => { clearTimeout(timer); timer = null; };
  return debounced;
}

// 节流：时间戳 + 定时器，保证首次立即执行、末次也不丢
function throttle(fn, wait = 300) {
  let last = 0, timer = null;
  return function (...args) {
    const now = Date.now();
    const remain = wait - (now - last);
    if (remain <= 0) {
      if (timer) { clearTimeout(timer); timer = null; }
      last = now;
      fn.apply(this, args);
    } else if (!timer) {
      timer = setTimeout(() => {
        last = Date.now();
        timer = null;
        fn.apply(this, args);
      }, remain);
    }
  };
}
```

**复杂度**：常数级开销

> ⚠️ **易错点**：返回的不能是箭头函数，否则 this 会被锁死在定义时的作用域，作为 DOM 事件回调时拿不到元素。

### 41. 深拷贝（处理循环引用）

难度：**中等**　|　来源：前端必考

**题目**：实现一个能正确处理循环引用和常见内置对象的 deepClone。

**思路**

- `JSON.parse(JSON.stringify(x))` 会丢掉函数、undefined、Symbol，把 Date 变成字符串，遇到循环引用还会直接抛错。
- 用 WeakMap 做缓存：拷贝前先查表，拷过就直接返回，循环引用自然解决。WeakMap 不会阻止垃圾回收。
- 注意先把新对象 set 进缓存，再递归拷贝属性，顺序反了循环引用还是会爆栈。
- Date、RegExp、Map、Set 要分别处理；用 `Reflect.ownKeys` 可以把 Symbol 键也带上。
- 现代浏览器已经有原生的 `structuredClone()`，但它不能拷贝函数，可以作为补充答案提一句。

```js
function deepClone(value, cache = new WeakMap()) {
  if (value === null || typeof value !== 'object') return value;  // 原始类型与函数
  if (cache.has(value)) return cache.get(value);                  // 循环引用

  if (value instanceof Date) return new Date(value);
  if (value instanceof RegExp) return new RegExp(value.source, value.flags);

  if (value instanceof Map) {
    const m = new Map();
    cache.set(value, m);
    value.forEach((v, k) => m.set(deepClone(k, cache), deepClone(v, cache)));
    return m;
  }
  if (value instanceof Set) {
    const s = new Set();
    cache.set(value, s);
    value.forEach(v => s.add(deepClone(v, cache)));
    return s;
  }

  const result = Array.isArray(value)
    ? []
    : Object.create(Object.getPrototypeOf(value));  // 保留原型链
  cache.set(value, result);                         // 必须先入缓存再递归

  for (const key of Reflect.ownKeys(value)) {       // 含 Symbol 键
    result[key] = deepClone(value[key], cache);
  }
  return result;
}
```

**复杂度**：时间 O(n)，空间 O(n)

### 42. 树形结构与扁平列表互转

难度：**中等**　|　来源：业务高频

**题目**：后端返回扁平的 { id, pid } 列表，前端组件需要嵌套的 children 树，两个方向都要会写。

**思路**

- 列表转树的朴素写法是双重循环 O(n²)，正确做法是先用 Map 建立 `id → 节点` 索引，再一次遍历挂载，O(n)。
- pid 找不到对应父节点的就是根节点。
- 树转列表用 BFS 队列，顺带把 pid 补回去；用解构把 children 摘掉，避免带进结果。
- 这是菜单、部门、评论、分类等业务里最常见的数据变换，比很多 LeetCode 题更实用。

```js
// 扁平列表 -> 树，O(n)
function listToTree(list, { idKey = 'id', pidKey = 'pid', childrenKey = 'children' } = {}) {
  const map = new Map();
  const roots = [];
  for (const item of list) {
    map.set(item[idKey], { ...item, [childrenKey]: [] });
  }
  for (const item of list) {
    const node = map.get(item[idKey]);
    const parent = map.get(item[pidKey]);
    if (parent) parent[childrenKey].push(node);
    else roots.push(node);
  }
  return roots;
}

// 树 -> 扁平列表（广度优先，顺带补回 pid）
function treeToList(tree, rootPid = null) {
  const res = [];
  const queue = tree.map(node => ({ node, pid: rootPid }));
  let i = 0;
  while (i < queue.length) {
    const { node, pid } = queue[i++];
    const { children = [], ...rest } = node;
    res.push({ ...rest, pid });
    for (const child of children) queue.push({ node: child, pid: node.id });
  }
  return res;
}
```

**复杂度**：时间 O(n)，空间 O(n)

> ⚠️ **易错点**：真实数据里 pid 可能是 0、null、''、undefined 混用，判断根节点时用「父节点是否存在」而不是「pid 是否为 0」。

### 43. 大数相加（字符串相加）

难度：**中等**　|　[LeetCode 415](https://leetcode.cn/problems/add-strings/)

**题目**：不使用 BigInt，把两个用字符串表示的非负整数相加。

**思路**

- JS 的 Number 只能精确表示 2^53−1 以内的整数，超过就会丢精度，所以要模拟竖式加法。
- 从两个字符串末尾往前逐位相加，维护进位 carry。
- 循环条件写成 `i >= 0 || j >= 0 || carry`，一次性处理掉长度不等和最高位进位。

```js
function addStrings(num1, num2) {
  let i = num1.length - 1, j = num2.length - 1, carry = 0;
  const res = [];
  while (i >= 0 || j >= 0 || carry) {
    const a = i >= 0 ? num1.charCodeAt(i--) - 48 : 0;  // '0' 的编码是 48
    const b = j >= 0 ? num2.charCodeAt(j--) - 48 : 0;
    const sum = a + b + carry;
    res.push(sum % 10);
    carry = sum >= 10 ? 1 : 0;
  }
  return res.reverse().join('');
}
```

**复杂度**：时间 O(max(m, n))，空间 O(max(m, n))

> ⚠️ **易错点**：追问「为什么不用 BigInt」时可以答：BigInt 兼容性和性能都有成本，且面试考的是进位逻辑本身。
