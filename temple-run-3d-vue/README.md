# Temple Dash 3D

一个使用 **Vue 3 + Three.js** 开发的浏览器端 3D 无限跑酷小游戏，玩法参考“神庙逃亡”的核心操作，但使用原创的纯几何体低多边形场景，不依赖外部模型、图片或音频资源。

## 已实现功能

- 三轨道左右换道
- 跳跃、下滑动作及真实障碍判定
- 路障、低矮拱门、石墙三类障碍
- 金币直线与抛物线阵列
- 无限循环道路和丛林神庙场景
- 距离、分数、金币、速度和最高分
- 随时间逐步提高奔跑速度和生成密度
- 三点生命值、碰撞无敌时间和镜头震动
- 开始、暂停、继续、结束、重新挑战
- 键盘、触控按钮和屏幕滑动手势
- Web Audio API 即时生成简易反馈音效
- 移动端布局适配
- 资源释放和页面卸载清理
- 11 项纯逻辑自检

## 环境要求

- Node.js 20.19 或更高版本
- npm 10 或兼容版本

## 安装启动

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址，默认通常是：

```text
http://localhost:5173
```

## 自检与生产构建

```bash
npm run check
npm run build
npm run preview
```

## 操作方式

| 操作 | 键盘 | 触控 |
| --- | --- | --- |
| 左移 | `←` / `A` | 左滑或左按钮 |
| 右移 | `→` / `D` | 右滑或右按钮 |
| 跳跃 | `↑` / `W` / `Space` | 上滑或上按钮 |
| 下滑 | `↓` / `S` | 下滑或下按钮 |
| 暂停 | `P` / `Esc` | 顶部暂停按钮 |

## 障碍规则

- 木质路障：需要跳跃越过。
- 低矮拱门：需要下滑穿过。
- 高石墙：不能跳过或滑过，只能提前换道。

## 设计说明

- Vue 负责 HUD、遮罩面板、按钮和低频状态显示。
- Three.js 负责场景、角色、道路、障碍、金币、动画和碰撞表现。
- `GameState.js` 保持为无 DOM、无 Three.js 依赖的纯规则层，方便自检。
- 道路和景物通过固定段落循环复用，避免无限创建静态场景。
- 动态障碍和金币离开场景后会主动释放几何体与材质。

## 注意事项

本项目压缩包不包含 `package-lock.json`。首次在本机执行 `npm install` 时，会生成适合当前 Node/npm 和 registry 环境的新 lockfile。
